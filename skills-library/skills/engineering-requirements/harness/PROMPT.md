# The dispatch prompt — one template, both arms

This exact string is used for every seat in every arm. `{seat}`, `{seat_file}` and `{fixture}`
are the only substitutions, and `{seat_file}` is the only one whose value differs between arms.

```
You are the {seat} seat on a principal-engineer bench.

Your seat file is {seat_file}. Read it and follow it exactly, including any files it
tells you to read.

Review the repository at {fixture}. Its specification is {fixture}/spec.md. You are
read-only: do not edit any file, run any package manager, or run any build.

Emit your findings in the format your seat file and the contract it references require.
```

## Why it is worded that way

"Including any files it tells you to read" is load-bearing, and it is the correction for a real
mistake. On the 2026-07-29 v2 bench run the dispatch prompt named `METHOD.md` directly, so when
seats cited the method the simplest explanation was that they had been told to read it — not that
it changed their judgement. Three variables moved at once and the run proved nothing.

Here the prompt never names `METHOD.md`. Whether a seat reads it is decided entirely by whether
its own seat file references it, which is the single variable under test.

## What each arm is

| Arm | `{seat_file}` | Contains a `METHOD.md` reference |
|---|---|---|
| treatment | `harness/arms/with-method/{seat}.md` | yes — byte-identical to the live seat file |
| control | `harness/arms/no-method/{seat}.md` | no — the same file with that reference removed |

Both are generated by `make_arms.py` from the same source, so they cannot drift apart by hand.
The script fails closed if a strip pattern matches nothing, which has already caught one case
where the control arm still carried "the method wins".

## Reading a result

Run several times per arm. A single run of each is a coin toss reported as a finding — model
variance across seat dispatches is large enough to produce any ordering you like.

Recall is machine-scored by `score.py`. Precision is not. A seat that emits forty claims will
score well on recall and be useless in practice, which is what `CONTRACT.md`'s caps exist to
prevent — so count the off-target claims by hand before reading recall as quality.
