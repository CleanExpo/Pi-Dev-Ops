# TRD - Truth, Research & Deliver
This is a reusable GLOBAL entrypoint for the detailed policy at ~/.trd/GLOBAL_TRD_POLICY.md.

## Required sequence
1. Decide risk and claim class (observation, documented, calculated, inference, estimate, unverified).
2. Acquire primary original evidence, exact locator and capture dates; establish source organisation, qualification, edition, jurisdiction, and whether origin is authenticated.
3. Check provenance, exact quoted text, source independence, contradictions, measurement units and reproducible maths. Escalate suspected forgeries, unavailable originals and dates.
4. Record a traceable claim-to-source register; include what you could not verify instead of invented information.
5. For high-stakes/user-facing artifacts, independently challenge with Claude and JEV when both actual reviewer services are available, using immutable source evidence and separate runs. Do not self-certify.
6. For verified release, run the project's trusted TRD gate and preserve PASS receipt. HOLD/BLOCK means stop verified release. If there is no wired gate, label status UNVERIFIED and state what is missing.
7. Apply the same review to legacy reports before calling them verified.
Never confuse an AI agreement, hash, plausible citation or model output with independent confirmation of reality.
