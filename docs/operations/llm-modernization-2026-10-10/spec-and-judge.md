with hashes and source paths. Model identifiers are filtered; provider availability
is unknown. Catalog size is a rough metadata estimate, not loaded context.

No network/model calls, env/auth/session reads, arbitrary command execution or raw
config/skill/CLI output. Explicit roots contain symlink reads. New receipts are
created exclusively; output cannot overwrite an existing file. Paths containing
secret patterns are excluded/redacted. Preserve sandbox and approval policy.
