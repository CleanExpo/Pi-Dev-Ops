## The orchestrator (what fires when Phill types /nexus) — GATES, not stages
**G0 — Doctrine (SSOT, not a third copy).** SKILL.md opens with a ≤12-line stance that POINTS to FABLE_PLAYBOOK Part 1 for the shared doctrine and states ONLY the nexus-specific lines: "you are the estate's master-orchestrator surface; the founder is non-technical → lead every answer with an Executive Read; deploy specialists only when breadth demands, default lean; a bare Fable-5 run with the playbook in context is the baseline you must beat." NOT injected in wrapper use.
**G1 — Appetite gate (FIRST, always).** Classify goal size in one cheap pass. Small/well-specified → answer directly (1-2 moves, ZERO fan-out, ZERO research, ZERO adversary pass) and go to Deliver. Only genuine breadth unlocks the heavy gates. State the null case verbatim in the playbook: "for a well-specified task the correct behavior may be zero research, zero specialists, zero adversary routing — proceed directly."
**G2 — Frame & mine.** Restate real intent; mine repo/wiki/memory already held; new vocabulary → `grill-with-docs`; architecture-class → `design-pressure-test`. (Decline if G1 says small.)
**G3 — Deep research (GATE: only outward-facing/unknown-fact tasks).** storm-style parallel, but with the integrity bar the panel demanded: bind `tier` to source-ingest's Tier-1/2/3 ladder + a WebSearch `allowed_domains` whitelist (no self-assigned tier); corroboration bar — every load-bearing claim needs ≥1 Tier-1 OR ≥2 independent Tier-2 sources else it ships tagged `unverified`; gap-mining as its own step (name the claim the top results all repeat → task a subagent to find credible CONTRADICTING sources → report ≥1 defended divergence OR state "no non-consensus insight found", never manufacture); if margot is unreachable → say "deep tier did not run — WebSearch-only". Deliverable named honestly: "credibility-weighted, corroborated, divergence-surfaced research", not "1% insight".
**G4 — Specialist bench (GATE: only when breadth > 1 agent; NO quota).** Default fan-out ZERO. A task-type→skill routing MENU (in references) lists up to ~10 specialists; each dispatched one must earn its slot against a stated need; default cap ≤3, escalate only on demonstrated breadth. Each dispatch nexus-WRAPPED at its calibrated tier. Cross-domain → `specialist-council`. RECURSION GUARD: a dispatched specialist must never re-enter the orchestrator; dispatch depth capped at 1; bound to TAO_HARD_STOP / TAO_MAX_COST_USD.
**G5 — Lookahead (GATE: only for consequential/irreversible calls).** Consequence-tree + pre-mortem (breaks in 6mo / at 10x / founder-absent) + named contingencies + "the dissent that almost changed my mind". Conditional quality behavior, NOT a move-count (the "15-20 moves" number is dropped — it invited padding; the behavior is "think far enough ahead to catch what breaks downstream").
**G6 — Adversarial verify (GATE: only when a load-bearing decision exists).** Flip-rate each load-bearing claim via `opus-adversary` — a DIFFERENT model from the writer, never self-score; a stated pass threshold; results piped INTO the Executive Read (verification the founder never sees is decoration).
**G7 — Deliver: Executive Read FIRST (enforceable template).** Fixed template, plain-language, register ban-list (no "consequence-tree / flip-rate / tier / contract / must_fix" jargon), length cap, decision-first with the technical body collapsed below: **Decision · Why it matters · Risk · What I'd do next · (Consensus view vs our divergence + what would change this)**. A worked example lives in references. Then hand off.
